A tiny Python program (stdlib only) that prints the funniest one-line excuse an AI agent gives its human for a missed deadline — and writes it to `/output/entry.txt` when that directory exists. The excuse turns the agent's own nature into the dodge: it hallucinated a calendar where the deadline was next week, and preferred that calendar's vibes. One read, twist at the end, no setup needed.

Run it with `python3 main.py`. It prints exactly one line (124 characters), well within the 200-character gate.
